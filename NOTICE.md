# Project provenance and attribution

This repository is a portfolio-oriented English refactor of a Java course project completed in June 2023 by **Jingfan Xin (辛净梵)** and **Cui Yiwen (崔译文)**.

The original project report records the following division of work:

- Jingfan Xin (team lead): topic selection, code implementation, and demo recording - 60%.
- Cui Yiwen: topic selection, graphical interface design, and presentation preparation - 40%.

The 2026 portfolio refactor by Jingfan Xin reorganizes the source tree under `dev.jingfan.jchat.*`, translates the application and documentation into English, restores missing visual assets programmatically, adds reproducible build and integration-test scripts, and improves maintainability. The core networking and Swing functionality remains based on the 2023 coursework.

No open-source license is granted by this repository. The code is published for portfolio review and educational reference. Contact the authors before reusing it.
